## 📌 Executive Pitch & Problem Statement

### *"Why AgentFDA is Impossible without GenLayer"*
In traditional clinical trials, **$50B+ annually** is locked in milestone-based pharmaceutical research grants. However, the adjudication process suffers from severe systemic vulnerabilities:
1. **Sponsor Bias & P-Hacking:** Centralized trial sponsors cherry-pick surrogate endpoints or suppress marginal adverse event rates to unlock escrowed capital.
2. **Oracle Problem in DeSci:** Standard EVM blockchains cannot ingest 500-page clinical trial dossiers, patient cohort outcomes (JSON/CSV), or real-time DSMB toxicity logs without centralized intermediaries.
3. **Subjective Clinical Consensus:** Evaluating whether a 4.2% Serious Adverse Event (SAE) rate constitutes a fatal safety breach versus expected background incidence requires biostatistical reasoning and consensus—capabilities native only to **GenLayer Intelligent Contracts**.

**AgentFDA** introduces an autonomous on-chain regulatory oracle. Validators running GenVM independently fetch live de-identified patient cohort data and DSMB safety audits via `gl.nondet.web.render`, formulate biostatistical evaluations using `gl.nondet.exec_prompt`, and converge on consensus using `gl.vm.run_nondet` semantic agreement.

## 🔒 Security & Semantic Consensus Design

1. **Meaning vs Schema Consensus:** Unlike trivial contracts that merely compare JSON keys, AgentFDA's `validator_fn` compares the actual biostatistical `verdict` and verifies the SHA-256 evidence hash. Variations in the natural-language rationale generated by independent LLM validators do not cause consensus deadlock.
2. **Anti-Prompt-Injection Canary:** Every nondet prompt includes a cryptographic `CANARY_AGENT_FDA_SAFETY_V1` token. Any prompt injection or hallucinated payload omitting this token is automatically terminated.
3. **Strict Separation of Duties:** Sponsors cannot claim trials as investigators (`Role Violation: Sponsor cannot act as independent trial investigator`).
4. **24-Block Dispute Cooling-Off Window:** Any stakeholder can challenge a verdict within 24 blocks by staking a mandatory 10% dispute bond.
